# Lieson 个人博客

无需构建工具的静态博客：首页是文章列表与写作方法，`articles/` 存放独立文章页。

## 发布到 GitHub Pages

1. 在 GitHub 新建公开仓库，例如 `lieson-notes`。
2. 将此文件夹内的全部文件上传到仓库根目录。
3. 打开仓库 **Settings → Pages**，在 **Build and deployment** 选择 **Deploy from a branch**、分支 `main`、目录 `/ (root)`，保存。
4. 数分钟后，GitHub 会提供 `https://用户名.github.io/lieson-notes/` 公开网址。

发布前请把首页与文章页中的 `hello@example.com` 改成真实联系邮箱，并用真实文章替换示例文章。
